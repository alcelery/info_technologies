# «Информационные технологии»

Это учебный репозиторий связанный с дисциплиной "Информационные технологии".

## Домашние работы

| № | Папка | Что сдаёте | Ветка |
|---|---|---|---|
| 1 | `lesson_01` | три события на сайте, путь пользователя, точка потери данных | `hw-01` |
| 2 | `lesson_02` | где бизнес теряет клиентов: воронка и настройка GA4 | `hw-02` |
| 3 | `lesson_03` | скриншоты: тег на сайте, источник перехода и отчёты GA4 | `hw-03` |
| 4 | `lesson_04` | четыре своих события на сайте и их параметры в GA4 | `hw-04` |
| 5 | `lesson_05` | форма сайта пишет заявки в Google Таблицу через Apps Script | `hw-05` |
| 6 | `lesson_06` | повторяемая очистка выгрузки заявок формулами Google Таблиц | `hw-06` |
| 7 | `lesson_07` | цепочка Instagram → ManyChat → сайт → заявка в таблице | `hw-07` |

## Курсовая работа

Проект по техническому заданию компании в отдельном репозитории, описание
работы и защита презентацией до 7 минут. Порядок сдачи, шаблоны README
и описания, план слайдов — в [`kursovaya_rabota`](kursovaya_rabota/README.md).
Ссылки сдаются бланком `kursovaya_rabota/kursovaya.md`.
